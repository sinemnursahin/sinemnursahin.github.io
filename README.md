# Sinem Nur Şahin — Personal Portfolio

Türkçe/İngilizce, responsive, renkli kişisel yazılım portfolyosu. Statik HTML/CSS/JavaScript kullanır; build aracı veya backend gerekmez.

## Yayına almadan önce
1. `index.html` içindeki proje kartlarına ilgili GitHub repo bağlantılarını ekleyin (URL'leri doğrulayın).
2. İsterseniz iletişim bölümüne profesyonel e-posta adresinizi ekleyin.
3. CV'nizi ekleyecekseniz yalnızca paylaşılmasını istediğiniz, kişisel/özel bilgi içermeyen sürümünü kullanın.

## GitHub Pages ile yayınlama
1. GitHub'da **New repository** seçin.
2. Repository adını tam olarak `sinemnursahin.github.io` yapın. (Kullanıcı adınız farklıysa kendi GitHub kullanıcı adınızı kullanın.)
3. Repository'yi **Public** oluşturun.
4. Bu klasördeki `index.html` dosyasını repository'nin kök dizinine yükleyin. `README.md` dosyasını da yükleyebilirsiniz.
5. Repository → **Settings** → **Pages** bölümüne gidin.
6. **Build and deployment** altında **Deploy from a branch** seçin.
7. Branch olarak `main`, klasör olarak `/(root)` seçip **Save**'e basın.
8. Yayın tamamlandığında `https://sinemnursahin.github.io` adresini açın. İlk yayın birkaç dakika sürebilir.

> GitHub Pages statik dosyaları yayınlar. Bu portfolyo kendi başına backend veya veritabanı çalıştırmaz. Yayınlanan site internette herkese açık olacağı için gizli bilgi eklemeyin.

Resmî rehber: https://docs.github.com/en/pages/quickstart
